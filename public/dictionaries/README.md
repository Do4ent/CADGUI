# Local spelling data

These unmodified Hunspell files are distributed with the application. The browser
loads only the selected language from this directory; drawing text is never sent
to a spelling service.

- `ru/`: `dictionary-ru` 3.0.0, Russian, BSD-3-Clause (Alexander I. Lebedev).
- `en/`: `dictionary-en` 4.0.0, US English, SCOWL/Hunspell terms reproduced in
  `en/LICENSE.txt`.

The complete upstream license notices are retained beside each dictionary.
Source packages: <https://github.com/wooorm/dictionaries>.

An engineering word may be accepted by the user dictionary. An accepted word is
an application preference, not a language-wide or standards certification.
