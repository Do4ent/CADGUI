# CADGUI — BendCore CAD Pro

This repository is intended to host the BendCore CAD Pro browser-based CAD interface prototype (React, TypeScript, Three.js), **without a CAD geometry kernel**.

## Project import status

Repository initialized. The complete v2.9 source archive has **not yet been imported**. Upload the contents of `bendcore-cad-pro-v29/` (not the outer folder) to the repository root before running CI.

The prepared project archive is available in the ChatGPT conversation as `bendcore-cad-prototype-v2.9-github-ci.zip`.

Once imported, run `npm install`, `npm test`, `npm run build`, and Playwright browser tests using `.github/workflows/ui-ci.yml`.
