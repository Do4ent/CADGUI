Дата проверки источников: 2026-11-02. Статус: **исследование и спецификация; функции каталога не реализованы этим PR**.

Сводка: **102 возможности в 12 группах**, по официальным материалам 22 CAD-систем и двум BIM-ориентирам. Это объединение функций без требования повторять меню конкретного продукта. Часть строк — дополнительные требования BendCore к качеству и безопасности данных.

Обзор не является исчерпывающей проверкой всех существующих САПР, редакций и лицензий. Наличие функции у одного продукта не означает её наличия у остальных. Источники могут описывать конкретные версии; ограничения проверки отмечены в таблице.

Машиночитаемый вариант: [DRAWING_TEXT_TOOLKIT.json](DRAWING_TEXT_TOOLKIT.json). Он не подключён к CommandRegistry и не объявляет команды доступными пользователю.

## Границы подсистем

| Сущность | Что входит | Ограничение |
| --- | --- | --- |
| Текст листа/вида | Одно-/многострочные блоки, форматирование и размещение | Основной предмет каталога |
| Заметка с выноской | Текст, линия, наконечник и опора | Ассоциативность требует устойчивых ссылок на геометрию |
| Размеры и инженерные обозначения | Значения, допуски, базы, сварка, шероховатость | Отдельные семантические сущности, не обычная строка |
| Технические требования | Пункты, номера, ссылки и размещение по страницам | Отдельный блок/документ, связанный с листами |
| Текст эскиза и объёмные буквы | Профили для гравировки/выдавливания | За рамками текущего инструментария чертежей; нужен геометрический backend |
| BIM-марки и 3D PMI | Категории/параметры модели и пространственные аннотации | Revit/Archicad дают ориентиры; совместимость с BIM/PMI не заявляется |

**A** — базовый редактор; **B** — связанные аннотации и подготовка документации; **C** — функции с отдельными сложными backend. Это порядок внутри текстовой подсистемы, он не отменяет текущие приоритеты IMPLEMENTATION_ROADMAP.md.

Указанные команды включаются по мере реализации capability; до этого недоступны с ясным объяснением, а не исполняют демонстрационную мутацию.

Редактор использует общие Dialog/ParameterField и технические SVG-иконки 16–20px, квадратные углы, обе темы, видимый фокус и inline-ошибки. Для ввода с размещением на листе нужна немодальная панель с доступным завершением/отменой.

Панель свойств: «Содержание», «Шрифт», «Абзац», «Положение», «Выноска», «Связи», «Печать». В редактируемом многострочном тексте Enter вставляет строку; Ctrl+Enter подтверждает, Escape отменяет текущий черновик. Клавиши модели во время ввода заблокированы. Общие диалоги ОК/Отмена/Apply сохраняют согласованные правила подтверждения.

## Порядок реализации и зависимости

1. **Основа листа**: настоящий 2D-лист и координаты бумаги, коллекция drawing-entities, жизненный цикл и выделение. Существующий режим «Чертёж» и список трёхмерных Item сами по себе этого не обеспечивают.
2. **Этап A**: редактируемые текстовые блоки, базовое rich text, стили, Unicode/символы, переносы, XY/поворот/якорь, маска, простая выноска, поиск и отмена. Сначала проверить метрики доступных шрифтов; сложные письменности не объявлять поддержанными без shaping-тестов.
3. **Этап B**: модель полей и устойчивых ссылок, штамп, технические требования, шаблоны, таблицы/спецификация, инженерные аннотации, наборы и проверки. Поля, для которых нет данных модели, показывают «нет данных», а не псевдорасчёт.
4. **Этап C**: двигатели SHX/сложной вёрстки, текст по дуге, DWG/DXF SDK, проверенный PDF backend, распознавание SHX и OCR. Лицензирование и возможности выбранных адаптеров проверяются отдельно.

Реалистичный первый PR реализации: сущность DrawingText + многострочный ввод, сохранение/повторное открытие, координаты/поворот/якорь и undo/redo на настоящем листе. Остальные функции добавляются отдельными PR после проверки базы.

## Контракты данных и команд

- Общий `TextContent`: абзацы, фрагменты оформления и типизированные поля; семантику полей не хранить только как уже вычисленную строку. Форматирование символов отделено от семантических допусков/размеров.
- `TextPlacement`: sheetId/viewId, XY, угол, якорь, ширина контейнера и система единиц. Масштаб интерфейса не переписывает размеры объекта.
- `TextStyleRef` и overrides: сохраняется исходный шрифт, реально использованная замена и состояние поддержки. CSS font-size и физическая высота CAD-глифа не считаются автоматически эквивалентными.
- `FieldRef`: тип источника, стабильный ID, имя свойства, формат и состояние связи; последнее отображённое значение может служить помеченным fallback, но не подменяет источник. Формулы — отдельный ограниченный вычислитель, не eval.
- `LeaderNote`, `TableCell`, `DimensionLabel` используют общее содержимое, но сохраняют собственную геометрию и семантику. Потеря ссылки вызывает видимое предупреждение и операцию восстановления.
- Черновик команды отделён от документа; подтверждение проверяет **всю** сущность до изменения истории/автосохранения. Групповая операция создаёт один undo-шаг. Отмена не меняет сохранённую модель.
- Новые drawing-entities не добавляются под видом box/cylinder/pipe в текущий Item[]. Нужны явная схема документа, миграция и тесты совместимости; этот каталог не задаёт фиктивный готовый номер версии CAD-документа.
- Экспорт объявляет capabilities: редактируемый текст/контуры, поля/статический снимок, поддерживаемые шрифты/знаки. Исходное содержимое и неподдерживаемые данные не уничтожаются молча.

## Проверки при реализации

| Область | Минимальные приёмочные сценарии |
| --- | --- |
| Сохранность | Кириллица/Unicode/переносы/оформление/поля сохраняются после reopen; старые документы мигрируют явно |
| Ввод | Пустой черновик и Escape не создают объект; невалидные числа/данные не попадают в историю и автосохранение |
| Редактирование | Создать → редактировать → отменить; два последовательных undo/redo; групповое изменение — один шаг |
| Метрики | Физическая высота на бумаге, базовые линии, переносы и рамки проверяются отдельно от CSS-предпросмотра |
| Связи | Изменение свойства/листа обновляет поле; удаление источника даёт управляемое состояние broken-link |
| Клавиатура | Enter/Ctrl+Enter/Escape, IME, Tab/Shift+Tab и возврат фокуса; команды модели не исполняются при вводе |
| Темы | Читаемые подписи, ошибки и выделение; визуальные снимки светлой/тёмной темы |
| Экспорт | Визуальный результат и извлекаемый текст PDF проверяются отдельно; неподдержанные свойства перечисляются |
| Распознавание | Низкая уверенность/ошибки распознавания требуют проверки; исходник остаётся доступным |

Этот PR добавляет исследование и каталог. Он не добавляет инструменты в работающий интерфейс и не объявляет поддержку DWG, SHX, OCR, нормативную сертификацию или геометрическое CAD-ядро.
