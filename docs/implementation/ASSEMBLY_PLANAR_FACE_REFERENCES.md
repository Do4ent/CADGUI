# Snapshot-bound planar face references for assembly occurrences

The Open CASCADE worker can inspect an exact BRep and return the planar faces of that snapshot. Each result contains an index in the full face traversal, a point on the supporting plane, and the face-oriented unit normal in body coordinates. The indices can have gaps because curved faces are excluded. Exact traversal and surface queries define the descriptors independently of triangles or mesh face groups.

Pass `brep => kernelClient.inspectPlanarFaces(brep)` as the inspector to `captureAssemblyPlanarFaceReference` and `resolveAssemblyPlanarFaceReference`. Capture takes the occurrence ID and exact face index. It returns a serializable reference with the occurrence ID, source body ID, SHA-256 digest of the exact UTF-8 BRep, and the face index. Plane coordinates are re-derived from the kernel after verification. Use the occurrence's resolved transform to convert the plane into assembly coordinates.

Resolution reports `broken` when an occurrence or exact source body is missing, `stale` when its source identity or BRep has changed, and `unavailable` when the verified snapshot has no planar face at that index. A different source body with identical BRep is stale. Occurrence placement, display metadata and reuse of the source body by another occurrence leave the underlying face unchanged. The SHA-256 digest uses the pinned @noble/hashes implementation. Inspector or environment failures reject the operation with an error.

Both calls operate on an immutable command snapshot. A UI consumer must guard the active document and source revision before committing asynchronous results. Keep this reference separate from transient viewport selection: the exact index applies only to the same BRep with the pinned OCCT version. Use the exact plane catalog to select a face by its native ordinal. Mapping viewport triangle clicks requires a separate verified mapping.
